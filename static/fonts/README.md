# Ayo font assets

The fonts are self-hosted; no third-party font request is needed at runtime.

- Syne variable, weights 400–800: headings and brand. Source: https://github.com/google/fonts/tree/main/ofl/syne
- DM Sans variable, optical size and weights 100–1000: interface and body text. Source: https://github.com/google/fonts/tree/main/ofl/dmsans
- DM Mono regular, weight 400: metrics and evidence metadata. Source: https://github.com/google/fonts/tree/main/ofl/dmmono

Downloaded 2026-10-25 without modification. Each font's copyright and SIL Open Font License 1.1 are included in the accompanying `OFL-*.txt` files.
