## Evidence rules

**VERIFIED LOCAL** means the implementation executed with named local/CI evidence; most provider cases use explicit offline fixtures. **PARTIAL** means functionality or acceptance remains incomplete. **PLANNED** means no working implementation exists. **BLOCKED LIVE** names an external dependency; it must not conceal independent implementation still required. **VERIFIED LIVE** applies only to the exact externally checked path, not automatically to production readiness.
